Streamlit Backend Integration Guide

1. Quick Local Streamlit Runner Script

Save the following code as app.py to run the Python backend triage model:

import streamlit as st

st.set_page_config(page_title="Nexonic Smart Enquiry Triage", page_icon="⚡")

st.title("⚡ Nexonic Smart Enquiry Triage Engine")
st.write("Autonomous intent & priority classifier for enterprise tickets.")

enquiry = st.text_area("Enter Enquiry Text:", placeholder="Type support request here...")

if st.button("Classify Enquiry"):
    if enquiry:
        # Mock sentiment & triage classification logic
        if "security" in enquiry.lower() or "breach" in enquiry.lower():
            category, priority = "SECURITY_ALERT", "P1 - CRITICAL"
        else:
            category, priority = "GENERAL_INQUIRY", "P3 - NORMAL"
            
        st.success(f"Category: {category}")
        st.warning(f"Priority: {priority}")
    else:
        st.error("Please enter text to classify.")

2. Execution Instructions

$ pip install streamlit pandas scikit-learn
$ streamlit run app.py
Server will launch locally on http://localhost:8501
